
# 🧞 EduGenie - Your Personal AI Learning Assistant

> Powered by Google Gemini 1.5 Flash

EduGenie is a smart learning companion that helps students to learn faster. It can clear doubts, generate notes, and create a personalized study plan in seconds.

### 🌟 Main Features
- 📚 **Instant Doubt Clearing** - Maths, Science, History ethuvum kekalam
- 📝 **Notes Generator** - Oru topic kudutha, full notes ready
- 🗓️ **Study Planner** - Exam ku munaadi personal timetable
- 💬 **Chat with AI Tutor** - 24/7 tutor maathiri pesum

### 💻 Tech Stack Used
| Technology | Use |
|---|---|
| Google Gemini API | AI Brain |
| Python - app.py | Main logic |
| Java - app.java | Backend support |
| JavaScript | Frontend interactivity |
| Streamlit | UI Design |
